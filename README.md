# BM100 – Buep Industries

Medidor de freno para puente grúa. Este repositorio lo consultan los equipos BM100 para buscar actualizaciones de firmware y está disponible para descargar el manual.

## Manual de usuario

[Descargar el Manual de Usuario del BM100 (PDF)](manuales/Manual_Usuario_BM100.pdf)

## Actualizar el firmware

Desde la interfaz web del equipo: **Ajustes → Versiones y actualización → Buscar actualización**. El BM100 tiene que estar conectado a una red WiFi con acceso a internet. Si hay una versión nueva, se instala con el botón **Instalar** y el equipo se reinicia solo.

Versiones publicadas: carpeta [`firmware/`](firmware/). La última está indicada en [`firmware/manifest.json`](firmware/manifest.json).
