## Manual de usuario

📘 [Descargar el Manual de Usuario del BM100 (PDF)](manuales/Manual_Usuario_BM100.pdf)

El manual también se puede descargar desde la interfaz web del equipo: tarjeta **Manual de usuario → Descargar PDF**.

## Actualizar el firmware

Desde la interfaz web del equipo: **Ajustes → Versiones y actualización → Buscar actualización**.
El BM100 tiene que estar conectado a una red WiFi con acceso a internet. Si hay una versión nueva, se instala con el botón **Instalar** y el equipo se reinicia solo.

La versión vigente se indica en [`firmware/manifest.json`](firmware/manifest.json).
